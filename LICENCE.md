## 🧩 About

**DayZ overlay** is a curated list of DayZ open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot tracker, map viewer
- **Quality-of-Life Helpers** — inventory catalog, config manager, overlay notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Survival Helpers
- Loot Tracker — note nearby item spawns on the map
- Map Viewer — study terrain and landmark layouts
- Status HUD — monitor hunger, thirst, and temperature notes
- Playback Notes — review movement routes for study

### 🎒 Catalog & Inventory
- Item Catalog — browse gear, weapons, and supplies
- Crafting Notes — organize recipe references
- Inventory Layout — improved stash visibility

### 🏋️ Practice Layout
- Map Markers — annotate points of interest
- Weather Notes — study day and night cycles
- Route Planner — chain travel paths in single-player

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"DayZ_x64.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Keep conservative defaults |
